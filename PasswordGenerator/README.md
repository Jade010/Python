# Password Generator App

## Overview
This is a GUI based password generator. This will allow you to generate a password between 8-15 characters long that has at least one Uppercase letter, lowercase letter, and number. Once you generate a password you can copy it with a click of a button. It is a very small but sweet project I made because I enjoy creating fake data that follows real world standards.

## How to Run

1. Install libraries:

   `pip install pyperclip`

3. Run the application:

   `python PasswordGenerator.py`
