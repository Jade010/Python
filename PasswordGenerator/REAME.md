# Password Generator App

## Overview
This repository contains a Python script, PasswordGenerator.py, that utilizes the tkinter library to create an application for generating a password. It allows you to choose the length of your password with built in error checking to ensure your password is within 8-15 characters long. The app then generates a password that has at least one upper case letter, lower case letter, number, and special character. A button allows the user to copy the password to their clipboard. It is a very small but sweet project I made because I enjoy creating fake data that follows real world standards.
